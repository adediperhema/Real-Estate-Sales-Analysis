# Real Estate Sales Analysis



Portfolio Performance report | Europe | United States



The objective of this project is to conduct a comprehensive analysis of Real Estate sales data to identify patterns, trends and significant factors influencing Profit/loss in a specific period of Time. This analysis aims to create insights on what property type is in high demand. It also shows Daily Trends of sales. This Project Analysis shows how location affected the market value and purchase values of All property Types



##### 1\. Key Performance Indicators Summary

It consolidates high-level portfolio performance variables across four key primary metric definitions:



•	Market Value: 275.90M — Current aggregated valuation of the property assets under management.



•	Purchase Value: 497.09M — Total capital outlay deployed to acquire the property portfolio. 



•	Total Profit: -221.19M — Expressed mathematically as Market Value minus Purchase Value (275.90M - 497.09M), indicating a deep severe capital deficit if tracking logic is correct.



•	Average Sales Ratio: 0.60 — Synthesized benchmark representing asset translation performance efficiency.



##### 2\. Chart-by-Chart Analysis



###### 2.1 Sales Profit Analysis (Stacked Column Chart)



This chart breaks down the Sum of Purchase Value grouped dynamically by Town and Property Type constraints:

•	New London: Commands the highest absolute capital concentration, topping out at \~135M. Operations here exhibit strong commercial real estate saturation (yellow visual markers), flanked by raw vacant land holdings.



•	Berlin: Holds the secondary volumetric market tier (\~113M), showcasing structured Commercial properties, localized industrial segments, and an expansive Vacant Land block.



•	Washington, Burlington, Coventry, and Derby: Present homogeneous asset structures consisting almost exclusively of Vacant Land holdings, leaving non-land real estate sectors fundamentally unrepresented.

##### 3\. Key Insights \& Strategic Recommendations

Vacant Land Asset Over-exposure: The investment base exposes severe visual concentration risk inside the Vacant Land categorization. Excluding the core baseline revenue generated in New London and Berlin, peripheral regions show total structural reliance on non-developed fields. 

Active rebalancing into multi-family residential or multi-tenant commercial structures is heavily advised to capture liquid yield channels.
